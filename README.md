# Автоматизированное тестирование API сервиса «Яндекс.Самокат» 

Проект содержит полный набор автоматизированных тестов для API сервиса «Яндекс.Самокат».
Тесты покрывают основные и дополнительные эндпоинты для работы с курьерами и заказами.

## Структура проекта


## Покрываемые сценарии

### Основное задание
- **Создание курьера** - успешное создание, проверка дубликатов, обязательные поля
- **Логин курьера** - успешная авторизация, ошибки входа, проверка возвращаемого ID
- **Создание заказа** - параметризация по цветам (BLACK, GREY, оба цвета, без цвета), проверка track-номера
- **Список заказов** - проверка возвращаемого списка заказов

### Дополнительное задание
- **Удаление курьера** - успешное удаление, обработка ошибок
- **Принятие заказа** - успешное принятие, обработка конфликтов, проверка ошибок
- **Получение заказа по трек-номеру** - успешный поиск, обработка ошибок
